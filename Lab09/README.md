### Задание 2 **(2)**

*Напишите функцию* **sublist** *для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```pycon
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

```python
def sublist(seq, *positions):
    return [seq[index] for index in positions]


lst = ['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']

print(sublist(lst, 0, 2, 5))           # ['Anna', 'Clara', 'Flora']
print(sublist(lst))                    # []
print(sublist(lst, 0, 1, 2, 3, 4, 5))  # ['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

`*positions` собирает переданные индексы в кортеж. Функция выбирает элементы в порядке указанных индексов и одинаково работает со списком и кортежем.

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

- *Если текущее число x в последовательности четное, то следующее число равно x/2.*
- *Иначе следующее число равно 3x + 1.*

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*

```pycon
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

```python
def gen(n):
    while n != 1:
        yield n

        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1

    yield n


print(*gen(7))
# 7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

Начальное `n` — положительное целое число. `yield` выдаёт текущее значение, а при следующем обращении генератор продолжает вычисление. Последний `yield` выдаёт единицу, в том числе при `n = 1`.

### Задание 7 **(2)**

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```python
def every_other(seq):
    ...
```

*Ниже приведены примеры использования генератра.*

```pycon
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

```python
def every_other(seq):
    for index, item in enumerate(seq):
        if index % 2 == 0:
            yield item


print(*every_other([10, 20, 30, 40, 50]))        # 10 30 50
print(*every_other(range(10)))                  # 0 2 4 6 8
print(*every_other(iter(range(10))))            # 0 2 4 6 8
print(sum(every_other(map(int, '2 5 11 3 8'.split()))))  # 21
```

По примерам отсчёт начинается с первого элемента, поэтому берём индексы `0, 2, 4, …`. `enumerate` получает элементы последовательно, поэтому генератор работает и с `map`, и с другими итераторами.

### Задание 10 **(1)**

*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

- **`file.readline|`** — *чтение строки из файла.*
- **len** — *определение длины строки или количества элементов в контейнере.*
- **list.append** — *добавление в список нового элемента.*
- **sum** — *нахождение суммы.*
- **sorted** — *построение сортированного списка.*
- **list.sort** — *сортировка списка.*
- **random.randint** — *генерация случайного целого числа.*
- *Разворот списка.*

  ```python
  def rev(x):
      return x[::-1]
  ```

- *Выбор нескольких элементов из хвоста списка.*

  ```python
  tail_len = 3
  def tail(x):
      return x[-tail_len:]
  ```

Чистая функция при одинаковых входных данных возвращает одинаковый результат и не имеет побочных эффектов. Для `len`, `sum` и `sorted` в таблице рассматриваем обычные встроенные коллекции, как в этой лабораторной.

| Функция | Чистая | Почему |
| --- | :---: | --- |
| `file.readline()` | Нет | Результат зависит от текущей позиции в файле. Чтение сдвигает эту позицию. |
| `len(x)` | Да | Возвращает длину переданного объекта. |
| `list.append(x)` | Нет | Изменяет исходный список. |
| `sum(x)` | Да | Возвращает сумму элементов коллекции. |
| `sorted(x)` | Да | Возвращает новый отсортированный список. |
| `list.sort()` | Нет | Переставляет элементы в исходном списке. |
| `random.randint(a, b)` | Нет | Результат зависит от состояния генератора случайных чисел, которое меняется при вызове. |
| `rev(x)` | Да | Срез `x[::-1]` создаёт новый список в обратном порядке. |
| `tail(x)` | Нет | Результат зависит от глобальной переменной `tail_len`. Если её изменить, один и тот же список может дать другой результат. |

Если передать в `sum` или `sorted` одноразовый итератор, вызов продвинет его до конца. Для такого аргумента у операции есть побочный эффект.

### Задание 11 **(2)**

*Рассмотрите следующую функцию.*

```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```

- *Что передается в функцию* **toint**? *Что возвращает эта функция?*
- *Что делает функция* **wrapper**?
- *Придумайте несколько примеров использования* **toint**.

```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper


max_int = toint(max)
add_int = toint(lambda a, b: a + b)
power_int = toint(pow)

print(max_int('9', '10', '2'))  # 10
print(add_int('12', 3.9))       # 15
print(power_int('2', '5'))      # 32
```

В `toint` передаётся функция `fun`. `toint` возвращает функцию `wrapper`, которая запоминает `fun`.

При вызове `wrapper` собирает позиционные аргументы в `args`, преобразует каждый через `int`, распаковывает их в вызов `fun` и возвращает её результат. Во втором примере `int(3.9)` даёт `3`, поэтому результат равен `15`.
